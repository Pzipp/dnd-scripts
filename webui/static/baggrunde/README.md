# Baggrunde

Læg dine egne baggrundsbilleder i denne mappe. Webui'en lister dem selv, så nye filer dukker op i vælgeren "Baggrund" (Karakterark og Kort) uden kodeændring - genindlæs bare siden.

* Filtyper: `.png`, `.jpg`/`.jpeg` og `.webp`. Andre filer ignoreres.
* Filnavnet vises som navn i vælgeren. Undermapper og skjulte filer (der starter med `.`) bruges ikke.
* På karakterark ligger billedet bag hele siden (A4). På kort ligger det bag hvert korts forside og bagside.
* Vælg lyse billeder med lav kontrast, så teksten kan læses. Til print: ca. 150-300 dpi (A4 = 1240 x 1754 til 2480 x 3508 px). Meget store filer gør forhåndsvisning og PDF langsomme.
* Filerne i denne mappe følger repoet (git). Læg kun billeder her, som gruppen må dele; repoet er offentligt.
* Billederne hentes kun via webui'ens egen rute, som kun udleverer filer fra listen ovenfor.
